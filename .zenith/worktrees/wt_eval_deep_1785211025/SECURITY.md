# 🛡️ Security Policy / Chính sách Bảo mật

## Supported Versions / Phiên bản được Hỗ trợ

Only the latest version of JKAI Zenith is currently supported for security updates.
*Hiện tại chỉ phiên bản mới nhất của JKAI Zenith được hỗ trợ cập nhật bảo mật.*

| Version / Phiên bản | Supported / Được hỗ trợ |
| ------------------- | ----------------------- |
| v6.x                | :white_check_mark:      |
| < v6.0              | :x:                     |

## Reporting a Vulnerability / Báo cáo Lỗ hổng

We take the security of JKAI Zenith seriously. If you find a vulnerability, please report it responsibly.
*Chúng tôi coi trọng bảo mật của JKAI Zenith. Nếu bạn tìm thấy lỗ hổng, hãy báo cáo một cách có trách nhiệm.*

**Do not report vulnerabilities through public GitHub issues.**
*(Không báo cáo lỗ hổng qua các GitHub issues công khai.)*

Please send an email to: **leetrung.jkai@gmail.com**
*(Vui lòng gửi email đến địa chỉ trên.)*

### What to include / Nội dung báo cáo:
- **Type of issue** (e.g., buffer overflow, injection).
  *(Loại vấn đề - ví dụ: tràn bộ đệm, lỗi injection.)*
- **Source location** (file path and line numbers).
  *(Vị trí nguồn - đường dẫn file và số dòng.)*
- **Reproduction steps** and Proof-of-Concept.
  *(Các bước tái hiện và bằng chứng thực nghiệm - PoC.)*
- **Impact assessment**.
  *(Đánh giá mức độ ảnh hưởng.)*

We will acknowledge receipt within 48 hours.
*Chúng tôi sẽ xác nhận đã nhận báo cáo trong vòng 48 giờ.*
