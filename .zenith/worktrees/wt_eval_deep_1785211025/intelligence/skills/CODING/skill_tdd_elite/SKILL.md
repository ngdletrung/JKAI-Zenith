# 🧪 Kỹ năng TDD Tinh nhuệ (TDD Elite)

## 🌟 TỔNG QUAN
Kỹ năng này áp dụng quy trình Test-Driven Development (TDD) chuẩn mực để đảm bảo chất lượng mã nguồn tối thượng.

## 🛠️ PHÁC ĐỒ VẬN HÀNH
### 🔍 Phase 1: Red (Thất bại)
- Viết các trường hợp kiểm thử (test cases) mô tả hành vi mong muốn.
- Chạy test và xác nhận chúng thất bại.

### 🚀 Phase 2: Green (Thành công)
- Viết lượng code tối thiểu nhất để vượt qua các bài kiểm tra.

### 💎 Phase 3: Refactor (Tối ưu)
- Cải thiện cấu trúc mã nguồn mà không làm thay đổi hành vi.
