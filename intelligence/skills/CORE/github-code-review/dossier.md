# DOSSIER: GITHUB_CODE_REVIEW

## 🌌 Overview
Đây là "Giám sát viên Tận tụy" (Diligent Auditor) của Zenith. Kỹ năng này đảm bảo rằng mọi dòng code được đẩy lên GitHub đều đáp ứng các tiêu chuẩn cao nhất về chất lượng, hiệu năng và bảo mật. Nó tự động hóa quy trình Code Review, giúp phát hiện sớm các sai sót trước khi chúng trở thành vấn đề lớn.

## 🛠️ Detailed Features
- **Semantic PR Analysis**: Phân tích ý nghĩa của các thay đổi trong Pull Request thay vì chỉ so sánh văn bản thô.
- **Bug & Vulnerability Detection**: Tự động phát hiện các lỗi logic phổ biến, các hàm bị lỗi thời (deprecated) hoặc các lỗ hổng bảo mật tiềm ẩn.
- **Best Practice Enforcement**: Đưa ra các gợi ý tái cấu trúc mã nguồn (Refactoring) dựa trên các tiêu chuẩn thiết kế phần mềm hiện đại và phong cách lập trình của Zenith.
- **Automated Commenting**: Tự động để lại các nhận xét (Comments) chi tiết và hữu ích trực tiếp trên giao diện GitHub PR.

## 🧠 Reasoning Strategy
AI nên sử dụng kỹ năng này khi:
1. Có một Pull Request mới cần được thẩm định trước khi Merge.
2. Cần rà soát lại chất lượng của một đoạn code phức tạp vừa được đẩy lên.
3. Muốn đảm bảo tính nhất quán về phong cách lập trình trong toàn dự án.

## 💎 Strategic Value
Duy trì "Độ sạch và Tinh khiết" (Cleanliness & Purity) cho mã nguồn. Code Review tự động giúp giảm tải cho Master LeeTrung, đồng thời tạo ra một lớp bảo vệ vững chắc chống lại các lỗi do sơ suất của con người.

## ⚠️ Edge Cases & Risks
- **False Positives**: AI có thể cảnh báo về các đoạn code thực tế là đúng nhưng có cấu trúc lạ (Unconventional).
- **Context Blindness**: Một số quyết định thiết kế đặc thù của dự án có thể bị AI hiểu lầm là lỗi nếu không được cung cấp đủ tài liệu ngữ cảnh.
