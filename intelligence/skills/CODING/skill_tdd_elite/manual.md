## 🎯 GIÁ TRỊ CHIẾN LƯỢC
Cốt lõi của sự ổn định Zenith. **Skill #17** ép AI phải viết Unit Test trước khi chạm vào mã nguồn thực tế.
- **Red Phase**: Viết test và chứng kiến nó fail.
- **Green Phase**: Viết code tối giản để test pass.
- **Refactor Phase**: Tối ưu hóa mà không làm hỏng tính năng.

## 🛠️ CÁCH VẬN HÀNH
Master hãy triệu hồi bằng lệnh:
> *"/run_skill #17"* hoặc *"Triển khai TDD cho tính năng X"*.

## 🦾 QUY TRÌNH THỰC THI (WORKFLOW)
1.  **Phân tích**: Xác định các tiêu chí chấp nhận (Acceptance Criteria).
2.  **Viết Test**: Khởi tạo các tệp `.test.ts` hoặc `.py` với các case thất bại.
3.  **Thực thi code**: Viết logic để "nhuộm xanh" các test case.
4.  **Tối ưu**: Refactor code chuẩn Elite.
