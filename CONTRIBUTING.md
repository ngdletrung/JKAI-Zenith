# 🤝 Contributing to JKAI Zenith / Đóng góp cho JKAI Zenith

First off, thank you for considering contributing to JKAI Zenith! It's people like you that make this project a great tool.
*Trước hết, cảm ơn bạn đã cân nhắc đóng góp cho JKAI Zenith! Chính những người như bạn đã làm nên sự tuyệt vời của dự án này.*

## 📜 Code of Conduct / Quy tắc Ứng xử

This project is governed by our [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
*Dự án này được điều chỉnh bởi [Quy tắc Ứng xử](CODE_OF_CONDUCT.md). Bằng việc tham gia, bạn được kỳ vọng sẽ tuân thủ quy tắc này.*

## 💡 How Can I Contribute? / Tôi có thể đóng góp như thế nào?

### 🐛 Reporting Bugs / Báo lỗi
- **Check Issues**: See if the bug has already been reported.
  *(Kiểm tra Issues: Xem lỗi đã được báo cáo trước đó chưa.)*
- **New Issue**: If not, [open a new one](https://github.com/MrLeeTrung/JKAI-Zenith/issues/new) with a clear title and description.
  *(Tạo Issue mới: Nếu chưa, hãy mở một issue mới với tiêu đề và mô tả rõ ràng.)*

### 🚀 Pull Requests
1. **Fork the repo** and create your branch from `main`.
   *(Fork kho lưu trữ và tạo nhánh của bạn từ `main`.)*
2. **Add tests** for new features.
   *(Thêm các bài kiểm tra (tests) cho tính năng mới.)*
3. **Update docs** if you changed APIs.
   *(Cập nhật tài liệu nếu bạn thay đổi API.)*
4. **Pass the suite**: Ensure all tests and linting pass.
   *(Kiểm tra toàn bộ: Đảm bảo tất cả các bài test và linting đều vượt qua.)*

## 🎨 Styleguides / Quy chuẩn Trình bày

### Git Commit Messages
- Use present tense ("Add feature") / *Sử dụng thì hiện tại.*
- Use imperative mood ("Move cursor to...") / *Sử dụng câu mệnh lệnh.*
- Reference issues/PRs. / *Trích dẫn các issue/PR liên quan.*

### Python Styleguide
- Follow **PEP 8**. Use **Black** for formatting.
  *(Tuân thủ PEP 8. Sử dụng Black để định dạng mã nguồn.)*
- Clear docstrings are mandatory.
  *(Bắt buộc phải có docstrings rõ ràng.)*
